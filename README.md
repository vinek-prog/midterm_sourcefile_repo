F1 Stack Simulator
Name: Bibanco,Kevin Clyde D.
Section: WMT 2-2
Course: BSIT

Description
This project provides the necessary files for a Stack Data Structure Simulator. It combines HTML for the webpage structure, CSS and Bootstrap for the design, and JavaScript with jQuery for handling user interactions and stack operations.

The simulator illustrates how a stack works using the Last In, First Out (LIFO) method, where the most recently added element is the first one removed.
